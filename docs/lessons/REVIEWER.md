# Lessons (Reviewer)

- **[PQueue.add / AbortSignal]** Flag any `PQueue({ concurrency: 1 }).add(fn, { signal })` call that passes a caller `AbortSignal` directly to `p-queue` without disconnecting it once the queued turn starts when `fn()` must hold the concurrency slot until completion, because `p-queue` races already-started tasks against `signal` and releases the `concurrency: 1` slot to the next waiter while `fn()` is still running in flight.
- **[StdioServerTransport / ReadBuffer]** Flag any `Readable` stream passed to `@modelcontextprotocol/sdk`'s `StdioServerTransport` that emits unnormalized string `'data'` chunks or enables `setEncoding('utf8')`, because `ReadBuffer.readMessage()` calls `subarray()` on the buffered chunk and throws `TypeError` when given a string instead of a `Buffer`.
- **[RuntimeExecutorRegistry / Multi-Port Adapters]** Flag any `create*Executors` factory that instantiates a fresh stateful adapter inside multiple `RuntimeExecutorRegistry` slices (such as `humanChannels` and `controlPlanes`) without memoizing per `(RuntimeDriverContext, canonicalNodeKey)`, because `@harness-dsl/core` resolves each slice independently and unshared instances lose cross-port state.
- **[PostgresClient / Lazy Async Wrappers]** Flag any lazy or async-factory wrapper implementing an interface with optional capability methods (such as `PostgresClient.connect`) that omits forwarding those optional methods, because `tsc` permits omitting optional properties while runtime callers checking `client.connect !== undefined` silently bypass connection pinning.
- **[Full `git ls-files` Lens Coverage]** Iterate the full `git ls-files` manifest for your lens across as many `view_file` batches as needed rather than relying only on `plan_file` §3 tables, because extra authored files or large directories (`> 100` files) omitted from your `view_file` calls fail Step 1.2 mechanical transcript verification.
