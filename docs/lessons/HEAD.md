# Lessons (Head)

- **[Pre-Proposal Library & Runtime Audit]** Verify end-to-end input-to-output coverage, permissive license compliance (`MIT`, `Apache-2.0`, `ISC`, `BSD-2-Clause`, `BSD-3-Clause`, `0BSD`, `Unlicense`), live maintenance/OSV health, and operational lifecycle costs (such as shared per-suite `@electric-sql/pglite` WASM memory teardown and native `node-pty` prebuild requirements) before presenting dependency options to the Owner, because unvetted recommendations waste Owner review turns on archived packages, partial solutions, or undisclosed memory/native-addon trade-offs.
