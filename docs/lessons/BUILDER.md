# Lessons (Builder)

- **[PQueue.add / AbortSignal]** Pass a queued-wait-only `AbortController` signal (`{ signal: waitController.signal }`) to `PQueue.add` and detach the caller's `AbortSignal` listener inside the task callback before invoking critical-section work or awaiting lock settlement when using `PQueue({ concurrency: 1 })` as a mutex or serialized queue, because `p-queue` wraps in-flight tasks in `Promise.race([fn(), abortPromise])` and immediately decrements `pending` (releasing the concurrency slot to the next queued waiter while `fn()` is still running) if the signal aborts mid-execution.
- **[StdioServerTransport / ReadBuffer]** Normalize incoming `'data'` chunks to `Buffer` (`Buffer.isBuffer(chunk) ? chunk : Buffer.from(String(chunk), 'utf8')`) and never call `setEncoding('utf8')` on a `Readable` stream passed to `@modelcontextprotocol/sdk`'s `StdioServerTransport`, because `ReadBuffer` stores the first chunk directly and calls `subarray()`, which is `undefined` on strings and throws `TypeError`.
- **[RuntimeExecutorRegistry / Multi-Port Adapters]** Memoize stateful adapter instances per `(RuntimeDriverContext, canonicalNodeKey)` via `WeakMap` when registering the same AST node type across multiple `RuntimeExecutorRegistry` slices (such as `humanChannels` and `controlPlanes`), because `@paraharness/core` invokes each port slice factory independently and fresh allocations split pending state across disconnected instances.
- **[PostgresClient / Lazy Async Wrappers]** Forward optional capability methods such as `connect()` when wrapping an async client factory (`getClient(): Promise<PostgresClient>`) into a lazy client proxy, because TypeScript allows omitting optional interface methods while `runInPostgresTransaction` checks `client.connect !== undefined` and silently skips connection pinning when `connect` is absent.
